# 🪄 Página Web Mago Iñigo

Este paquete contiene la estructura completa del sitio web interactivo para el **Mago Iñigo**.

## 📁 Estructura de Archivos

```text
mago-inigo-web/
├── index.html                  # Sitio web completo (HTML + CSS + JS interactivo + Web Audio)
├── crear_estructura.sh         # Script ejecutable en Linux / macOS
├── crear_estructura.bat        # Script ejecutable en Windows
├── crear_estructura.py         # Script ejecutable en cualquier sistema con Python
├── README.md                   # Instrucciones
└── img/                        # Carpeta de imágenes
    ├── laboratorio-burbujas.jpg # Foto para el show de 30 min
    ├── show-magia.jpg           # Foto para el show participativo
    ├── magia-intima.jpg         # Foto del público cercano
    └── gran-escenario.jpg       # Foto del escenario masivo
```

## 🚀 Cómo usar
1. Descomprime este archivo `.zip`.
2. Para probar la página localmente, simplemente haz doble clic en `index.html`.
3. Para publicar en internet gratuitamente, sube la carpeta completa a **Netlify**, **Vercel** o **GitHub Pages**.
